# Security policy

## English

This project is intended for trusted personal machines, homelab use, and local-first deployments.

Security expectations:
- treat the machine as trusted
- enable network exposure only when you understand the consequences
- review `Tailscale` usage before exposing the UI
- treat OpenCode/agentic actions as privileged local operations

If you discover a security issue, please do **not** open a public issue with exploit details. Report it privately to the maintainer first.

## Srpski

Ovaj projekat je namenjen za pouzdane lične mašine, homelab upotrebu i local-first deployment.

Bezbednosna očekivanja:
- mašina treba da bude poverljiva
- mrežno izlaganje uključuj samo ako razumeš posledice
- proveri `Tailscale` upotrebu pre izlaganja UI-ja
- OpenCode/agentske akcije tretiraj kao privilegovane lokalne operacije

Ako pronađeš security problem, nemoj odmah otvarati javni issue sa exploit detaljima. Prvo ga prijavi maintaineru privatno.
