# Troubleshooting / Rešavanje problema

## English

### Installer finished but runtime is not healthy

Open the `Repair` tab and run the appropriate repair action. The project is designed so the user should not need to use the terminal for standard recovery.

### OpenCode starts but does not answer

Check:
- model server health
- selected working directory
- current model/provider configuration

### Linux arm64 and TurboQuant

`TurboQuant` is intentionally unsupported on Ubuntu arm64 in this public installer line.

## Srpski

### Installer je završio, ali runtime nije zdrav

Otvori `Repair` tab i pokreni odgovarajući repair tok. Cilj projekta je da standardni recovery ne traži terminal.

### OpenCode se pokreće, ali ne odgovara

Proveri:
- health model servera
- izabrani working directory
- trenutnu model/provider konfiguraciju

### Linux arm64 i TurboQuant

`TurboQuant` je namerno nepodržan na Ubuntu arm64 u ovoj javnoj installer liniji.
