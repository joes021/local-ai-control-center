# Contributing

## English

Contributions are welcome, but this repository is strongly installer- and product-flow-oriented. Please prefer:
- installer reliability fixes
- runtime parity improvements
- repair/recovery improvements
- UI clarity improvements
- documentation that helps real users install and recover successfully

## Srpski

Doprinosi su dobrodošli, ali ovaj repo je snažno orijentisan na installer i product flow. Prednost imaju:
- popravke pouzdanosti instalera
- runtime parity poboljšanja
- repair/recovery poboljšanja
- UI poboljšanja koja povećavaju jasnoću
- dokumentacija koja pomaže stvarnim korisnicima da uspešno instaliraju i oporave sistem
