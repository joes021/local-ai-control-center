v2.24.8
- Linux installer sada prihvata vec aktivan/lokalno prisutan model kao validan bootstrap kandidat, pa reinstall na masini koja vec ima zdrav model vise ne pada na `bootstrap-not-ready`.
- `download-failed` sada cuva stvaran razlog iz bootstrap download koraka, pa installer report vise nije slep ako preporuceni model ne uspe da se preuzme.

v2.24.7
- Browser tabela sada popunjava GGUF velicine preko Hugging Face `tree` API-ja kada osnovni model API ne vrati `siblings.size`, pa velicine vise ne ostaju `Unknown`.
- Browser redovi sada cuvaju pravi `repoId`, pa `Download` iz same tabele i detail panela koristi validan katalog zapis umesto praznog repo identifikatora.
- Direktni link `Open model page` ostaje dostupan iz same Browser tabele.
- Linux `OpenCode` otvaranje iz LAICC ostaje kroz terminal launcher, a ARM Browser fixevi su objedinjeni u isti patch release.

v2.24.6
- Browser refresh vise ne rusi ekran kada se klikne `Refresh from internet`; refresh payload se sada prikazuje kroz bezbedan rezultat umesto kroz pogresan ActionResult shape.
- Browser tabela sada dobija stvarne velicine (`sizeBytes` / `sizeLabel`) iz source kataloga, pa GGUF fajlovi vise ne zavrsavaju kao `Unknown` kada API vrati poznatu velicinu.
- Browser download sada radi i bez prethodnog rucnog `Add to local catalog`: backend registruje model pa odmah pokrece download tok.
- Iz same Browser tabele sada postoji direktan link `Open model page` ka Hugging Face / Unsloth stranici modela.
- Linux installer vise ne pregazi vec aktivan model ako je sistem vec imalo zdravo aktivno runtime stanje; bootstrap model postaje aktivan samo kada aktivni model nije vec razresen.
- Linux `OpenCode` pokretanje iz Control Center-a sada ide kroz `desktop-launch.sh`, tako da se TUI zaista otvara u terminal emulatoru umesto da se poziv izgubi u pozadini.

v2.24.5
- Linux installer model bootstrap vise ne zavisi od legacy `manage-models.sh` mapiranja za obavezni bootstrap korak, nego direktno skida iz zajednickog recommended-models kataloga.
- Linux `OpenCode` launch iz Control Center-a sada koristi isti `start-opencode.sh` launcher tok koji radi i pri rucnom terminal pokretanju, umesto sirovog `opencode` executable poziva.
- GitHub storefront i release linkovi su poravnati na `v2.24.5`.
